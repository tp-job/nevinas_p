# Design System: Typography

## Font Families
- **Primary (Sans):** `Inter, system-ui, sans-serif`
  - *Usage:* Body text, navigation, UI elements.
- **Subtitles (Japanese/Display):** `Zen Kaku Gothic New`
  - *Usage:* Overview headers (`概要`), technical subtitles.

## Scale
| Level | Size | Weight | Line Height |
| :--- | :--- | :--- | :--- |
| Display | `3rem (48px)` | `800` | `1.1` |
| Heading 1 | `2.25rem (36px)`| `700` | `1.2` |
| Base | `1rem (16px)` | `400` | `1.5` |
| Caption | `0.75rem (12px)`| `500` | `1.4` |
